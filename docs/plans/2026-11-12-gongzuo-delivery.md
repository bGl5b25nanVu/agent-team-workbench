### 团队与工作协议

| 角色 | 主要职责 | 默认探索 |
|---|---|---|
| 总管 / Coordinator | 澄清目标与验收条件、拆解阶段、分派任务、核对交接、汇总交付 | 有限探索 |
| 研究员 / Researcher | 查证来源、区分事实与推测、解释不确定性、提出有证据的建议 | 有限探索 |
| 工程师 / Engineer | 实现功能、集成修改、处理缺陷、提交可复现的验证记录 | 有限探索 |
| 设计师 / Designer | 设计流程、交互状态与视觉方案，检查实现后的体验 | 开放探索 |
| 测试员 / Tester | 独立验证、提出反例、报告可复现缺陷与覆盖边界 | 有限探索 |
| 运营 / Operator | 整理文档、使用说明和交付材料，在已有授权内准备发布 | 稳健执行 |

三种模板分别选择研发 6 人、研究 4 人、内容 4 人。三档探索方式写入可编辑指令：稳健执行遵循既定路线；有限探索比较最多两个方案；开放探索提出三个方向后验证并收敛。

完整角色指令、团队公约、交接格式、验收规则、返工与升级约定保存在 [运行协议](2026-11-12-agent-team-workbench.md)，并作为共享预设进入真实成员配置。

### 实际行为

- 向导支持姓名、职责、模型或本地 CLI 来源、完整指令、探索方式、权限预设、目录、形象及复用成员。
- 新团队成员保存为待命状态。创建团队、重复同一请求、修改配置不会触发欢迎或任务模型调用。
- 首个 Goal 启动协调者；其他成员收到有效委派或直接消息后才运行。
- 每个新团队成员分派前核对其精确模型路由，并向实际接收任务的 Session 应用有效权限。模型消失、选型失败或权限应用失败时停止该任务，不静默回退。
- 持久创建记录保存已知成员和群 ID。同一操作 ID 去重；已知部分失败可继续；未知结果保留回执并停止自动重试，不声称所有外部副作用绝对只发生一次。
- 工作台读取真实 Goal、阶段、任务和成员状态。待办中心读取真实问题与审批，并遵守实际可回答状态。

### 本轮浏览器补验的实际证据

运行环境为独立的 Simular 测试目录、Chrome 157、Node.js 24.21 和固定 DSH `0.2.2-rc.1`。使用现有脚本模型与隔离 profile，保留正常鉴权，没有读取用户实际 DSH 数据或真实模型密钥。

- [建队流程报告](../design/verification/2026-11-12-resume/final-ui/result.json)：13 个步骤覆盖三种模板、成员选择、名称、实际模型和权限预设、自定义指令保护、形象切换、草稿刷新、确认创建、保存后设置、工作台与待办，以及手机和平板导航。

- 回答证据核对真实 `selected: ['改标题']`、问题 ID、call ID 与 Coordinator Session，避免把旧回合或同名选项误认成当前问题的回答。
- 群和私聊的后台记忆请求按实际回执单独分类；它们不被误计为另一位 Agent 启动，也不作为没有依据的“后台噪声”忽略。
- 额外只读核账覆盖全部 10 条请求：协调者群会话 1 条、群记忆复核 1 条、协调者私聊 4 条、私聊记忆复核 4 条；未知归属为 0，其余五位成员仍待命。本地 57 步 smoke 结束后已停止其测试服务。

上一轮真实 DSH 服务可启动，但共享浏览器预览转发失败；本地 Chromium 被拒绝 socket 操作；官方 headless-shell 下载返回 Site Unavailable。因此上轮正确标记为 `blocked`，没有声称获得实际运行截图。

本轮一次本地重试仍遇到原限制，随后在已连接云电脑完成真实 Chrome 运行，发现并修复角色图片 400、手机底栏遮挡、透明图边框和中文标签问题。自动交互、主题和图像检查通过后，已直接打开 1487 × 1058 的浅色建队页、成员检查器与选定参考对照，并复核手机建队页/底栏、深色建队页、工作台和已答复的问题画面。详细历史、证据及结论见 [design-qa.md](../../design-qa.md)，最终状态为 `passed`。

最终复核确认：六种角色插图完整且没有方形头像边框；蓝白三栏和六张角色卡符合选定方向；标题、字段与选择态层级清楚；390px 手机双列卡片可滚动，底栏成员数和独占一行的主按钮均可读且无重叠；深色主题文字与图像清晰。实现保留了实际产品的导航、待办、聊天及更详细运行设置，使用系统字体和较紧凑卡片，这些是明确接受的差异，不声称逐像素复刻。截图中的英文名字是测试自定义成员名。

### 模拟模型验证的范围

浏览器脚本使用真实 DSH、真实页面与模型请求回执，但模型回复由测试脚本提供。这证明已覆盖的交互、保存、唤醒范围和问题答复链路，不能证明真实模型质量或完整的 Goal 规划、阶段推进与最终交付。权限审批按钮操作及网络故障恢复注入未在本轮浏览器脚本中覆盖；后端创建恢复有独立的单元/API 检查。

### 约束的准确边界

职责、探索档位、交接证据和独立评审是写入指令的工作协议；实际模型路由、权限预设和创建状态由代码处理。尚未实现强制独立评审批准、自动测试验收门禁、硬预算、并发文件锁或不可修改的角色政策。界面不把这些建议性规则描述成系统已强制保证的能力。
